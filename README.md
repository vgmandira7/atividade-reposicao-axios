# Atividade de reposição da materia de PDM
   Nessa atividade iremos consumir uma API utilizando AXIOS, criando uma tela para mostrar os dados recuperados. Além disso fazer tratamento de erros utilizando try/catch e uma tela de carregamento. 


# Para testar: 
   Clonar o projeto: 
   ```bash
      git clone <Link-do-projeto>
   ```

   Baixar as dependências:
   ```bash
      npm intall
   ```

   Rodar o projeto:
   ```bash
      npx expo start
   ```
